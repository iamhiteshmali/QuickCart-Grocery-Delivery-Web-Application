# 🛒 QuickCart – Grocery Delivery Web Application

QuickCart is a modern full-stack grocery delivery web application that allows users to browse grocery products, manage their shopping cart, place orders, and manage their delivery details through an easy-to-use interface.

The project is built with a modern frontend and backend architecture using React, Vite, Node.js, Express.js, and database integration.

## ✨ Features

### 👤 User Features

- User registration and login
- Browse grocery products
- Product categories
- Product details
- Add products to cart
- Increase/decrease product quantity
- Remove products from cart
- Cart total calculation
- Delivery charge calculation
- Tax calculation
- Checkout system
- Delivery address management
- Order placement
- Order details
- Payment method selection
- Cash on Delivery option

### 🛠️ Admin Features

- Admin dashboard
- Product management
- Add products
- Update products
- Delete products
- View products
- Order management
- Update order status
- Manage grocery inventory
